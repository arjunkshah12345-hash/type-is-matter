# TYPE IS MATTER — Experiment 001
Interactive physical typography: chrome letters (NOTHING / STAYS / STILL) simulated with Rapier 3D, rendered with Three.js.
`npm install` · `npm run dev` · `npm run build` · `npx playwright test` (needs the dev server on :5173).
Fonts: Archivo Black and IBM Plex Mono (SIL OFL 1.1, licences in public/fonts). Hand tracking: MediaPipe Tasks Vision, processed locally.
